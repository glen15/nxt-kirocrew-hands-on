# 자료 요약 HTML 리포트

여러 개의 마크다운(.md)과 CSV(.csv) 파일을 읽어 요약하고, 하나의 HTML 리포트로 만든다.
문서는 요약 문단으로, CSV의 핵심 내용은 표로 담는다.

## 역할 분리

- **AI가 하는 일(판단)**: 파일 내용을 읽고 요약한다. 각 문서의 핵심을 문장으로 정리하고,
  CSV에서는 리포트에 표로 담을 핵심 열·행을 직접 골라 정리한다. 큰 CSV는 전부 넣지 말고
  핵심만 추린다(합계·상위 항목·상태별 건수 등). 애매하거나 근거가 부족한 값은 추측하지 말고
  요약 문장에 '확인 필요'로 남긴다.
- **Python이 하는 일(조립·검증)**: `scripts/build_report.py`는 파일을 읽지도 요약하지도 않는다.
  AI가 만든 요약 JSON의 스키마를 검사하고, 통과하면 모든 셀을 HTML 이스케이프해 HTML로 조립한다.

## 실행 절차

1. 대상 폴더의 파일 목록을 확인한다(어떤 md·csv가 있는지).
2. AI가 각 md를 읽어 요약하고, 각 csv를 읽어 표로 담을 핵심을 고른다.
   - 큰 CSV는 Python 등으로 먼저 집계해 핵심 수치를 얻고, 그 결과를 표로 담는다.
   - 검증된 집계 스크립트 결과 수치는 그대로 인용하고, 값을 눈대중으로 옮겨 적지 않는다.
3. 요약을 아래 스키마의 JSON으로 만든다.
4. 저장 전에 같은 이름의 출력 파일이 이미 있는지 확인하고, 있으면 덮어쓰지 말고 사용자에게 알린다.
5. `scripts/build_report.py`로 검사·생성한다. 검사를 통과한 경우에만 HTML이 저장된다.

```bash
cd ~/.kiro/crew/skills/data-to-html
# 요약 JSON으로 HTML 생성
python3 scripts/build_report.py 요약.json 리포트.html
# 또는 표준입력으로 전달
cat 요약.json | python3 scripts/build_report.py - 리포트.html
```

## 입력 JSON 스키마

최상위 객체는 다음 4개 필드를 갖는다. 필드 이름·자료형은 `scripts/build_report.py`의
`build_html`에서 검사한다.

| 필드 | 자료형 | 설명 |
|---|---|---|
| `title` | 문자열 | 리포트 제목 |
| `generated_on` | 문자열 | 생성일 등 부제(자유 문자열) |
| `documents` | 객체 목록 | 문서(md) 요약. 각 항목: `source`, `summary`, `key_points` |
| `tables` | 객체 목록 | CSV 핵심 표. 각 항목: `source`, `caption`, `columns`, `rows`, `notes` |

### `documents[]` 항목

| 필드 | 자료형 | 설명 |
|---|---|---|
| `source` | 문자열 | 원본 파일명 등 출처 |
| `summary` | 문자열 | 요약 문단 |
| `key_points` | 문자열 목록 | 핵심 bullet (빈 목록은 `[]`) |

### `tables[]` 항목

| 필드 | 자료형 | 설명 |
|---|---|---|
| `source` | 문자열 | 원본 CSV 파일명 등 출처 |
| `caption` | 문자열 | 표 제목 |
| `columns` | 문자열 목록 | 표의 열 이름들 |
| `rows` | 목록의 목록 | 각 행. 행의 길이는 `columns` 길이와 같아야 한다 |
| `notes` | 문자열 | 표 아래 보조 설명(없으면 빈 문자열 `""`) |

## 검사 규칙과 종료 코드

- 최상위 필드 누락·추가, 자료형 오류가 있으면 **저장하지 않고** 이유를 출력한다.
- `tables[].rows`의 각 행 길이가 `columns` 길이와 다르면 **저장하지 않는다**.
- 모든 텍스트 값은 HTML 이스케이프되어 삽입되므로 `<`, `&` 등이 그대로 표시된다.
- 종료 코드: `0` 검사 통과·저장 완료, `1` 검사 실패(저장 안 함), `2` 사용법·입출력 오류.
- 다크모드에서도 글자가 보이도록 배경·글자색을 고정한다(템플릿에서 처리).
